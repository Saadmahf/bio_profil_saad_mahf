03 · Low-level path

From C code to the pins: TX and RX

Click a block. Bits move along the TX path when a frame is transmitted.
Why PIO
  • No CAN peripheral on the RP2040: framing, stuffing and timing must be done by the tool itself.
  • Bit-banging from the CPU jitters with interrupts and cache/flash latency; a PIO state machine runs one instruction per clock with no jitter.
  • The clock divider sets the time quantum; side-set drives TX in the same cycle as the instruction.
  • The RX state machine waits for the SOF falling edge (hard sync), then samples at the sample point and resynchronises on recessive→dominant edges.
  • The CPU only builds frames, checks CRC and serves the application; FIFOs / DMA decouple it from bit time.
