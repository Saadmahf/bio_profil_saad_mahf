01 · Architecture

What the model contains

Model data flowSimulink top level, simplified
Power pathfollows the replay below
SOC: an extended Kalman filter per cell on a 1-RC model, checked against coulomb counting.
SOP: available charge/discharge current and power, used to limit the current request.
Web console: FastAPI + MATLAB Engine to drive the live model, plot any signal and run test scenarios.
