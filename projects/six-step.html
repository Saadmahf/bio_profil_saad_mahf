03 · Firmware-style adaptations

Three ideas taken from embedded firmware

Mode decision · geometric vs hysteresis15 → 1 switches
Low-pass filter scaled by ωr plus a Schmitt trigger (1.00 / 0.92). The exact hexagon test chatters during the PI start-up transient; the filtered flag does not.
Commutation instant · ZOH grid vs exactone vertex change
Knowing ωr, the switch time is computed analytically: the vertex changes 82.8 µs before the 100 µs grid would allow (over 80% of a sample).
Third adaptation: overmodulation tested directly in abc, max(V) − min(V) > Vdc. It matched the hexagon test on 500 random points and all 4000 run samples, with no trigonometry.

04 · Method & limits

Modelling choices

  • Model built by script (add_block / add_line): flat and reproducible.
  • One Memory block breaks the Part II ↔ PI algebraic loop, as a real digital controller would.
  • Part III implemented from the text of Section IV-C, the clearer source.
  • 10 µs fixed step, controller at 100 µs (exact integer ratio).
  • 37 unit checks on the control code, run outside Simulink.
  • Added: Vclamp3 = 0.5·Vdc on the Part III correction (without it id overshot to −78 A).
  • PI gains are not published: settling is 35–40 ms here vs 7–11 ms in the paper.
  • The paper's voltage-angle-control baseline is not implemented.

Reference: Y.-C. Kwon, S. Kim, S.-K. Sul, “Six-Step Operation of PMSM With Instantaneous Current Control,” IEEE Transactions on Industry Applications (2012 per the project brief).
